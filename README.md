## Descripción del Repositorio

Este repositorio contiene la solución completa a un taller práctico enfocado en el desarrollo del pensamiento lógico, la resolución de problemas algorítmicos y la representación gráfica mediante diagramas de flujo. 

Cada ejercicio incluye:
* **Enunciado:** Planteamiento original del problema.
* **Análisis:** Explicación lógica del razonamiento aplicado para llegar a la solución.
* **Pseudocódigo:** Estructura algorítmica formateada para entornos como PSeInt.
* **Diagrama de Flujo:** Representación visual almacenada en la carpeta `/diagramas/`.
